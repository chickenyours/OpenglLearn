# 性能优化记录（2026-09-27）

## 1080P 规则瓦片版本

`tiles_1080.csv`：1920×1080、946 个地形格 / 1029 个初始实体、Debug、静音、关闭垂直同步，90 帧去掉前 5 帧。物理均值 1.71942 ms，提取及组帧 3.86235 ms，整帧均值 5.94032 ms，P95 6.9826 ms，约 168.34 FPS，每帧 7 条 RHI 命令。地形与像素素材已经改变，此结果是当前版本的运行记录，不是与旧地图隔离变量后的性能对比。

实际 GPU 截图验证为 1920×1080；瓦片网格、自动边缘选择、存档激活及既有接触物理回归通过。静态地形不加入运动积分列表，碰撞先进行廉价轴对齐包围盒排除，避免增加瓦片数后逐格构建蒙版变换。

## 逐像素蒙版与新角色版本

新增 alpha 蒙版判定、新角色动画和推荐物理参数后，`masks.csv` 记录本机最新 90 帧测试（去除前 5 帧）：物理均值 3.14212 ms，整帧均值 4.40845 ms，P95 6.7273 ms，约 226.84 FPS，每帧仍为 7 条 RHI 命令。关闭垂直同步、静音、Debug 构建。当前移动/首跳/二段跳/重力为 18/56/52/100；由于物理规则和轨迹不同，下面的旧版结果仅供历史参考，并非相同工作负载下对蒙版额外开销的隔离测量。

## 之前的渲染性能优化

同一台 Windows 机器，OpenGL 4.5 / Intel 驱动 32.0.101.6790，1280×720，根项目原有 Debug 配置（未靠改为 Release 提升数据）。
前后均运行 90 帧固定回放：每个显示帧两次 120 Hz 物理更新，向右移动、每 30 帧跳跃、每 60 帧复位。包含真实碰撞、动画、死亡处理、提取、HUD、GPU 提交和交换缓冲。
舍弃前 5 帧，统计 85 帧。前后无垂直同步测试均静音。

| 指标 | 优化前 | 最终优化后 |
|---|---:|---:|
| 物理/游戏 CPU 更新均值 | 22.1014 ms | 0.259629 ms |
| 提取及组帧 CPU 均值 | 1.78809 ms | 0.86524 ms |
| 渲染线程执行均值 | 1.95817 ms | 0.060731 ms |
| 从游戏更新开始到帧完成回调的均值 | 37.0702 ms | 2.71974 ms |
| 相同口径 P95 | 46.9325 ms | 6.4084 ms |
| 1000 / 平均整帧耗时 | 26.98 FPS | 367.68 FPS |
| 每帧 RHI 命令均值 | 4803.56 | 7 |

原始数据：`before.csv`、`after.csv`。最终保留垂直同步的同场景验证见 `vsync.csv`：平均 13.2913 ms，约 75.24 FPS，P95 22.7569 ms。
数值是本机短基准结果，会受调度、驱动和显示器影响；不开垂直同步的吞吐并不代表屏幕实际刷新率。
render_thread_ms 是 CPU 渲染线程执行时间，不是 GPU timestamp 测量；total_ms 包含异步上传和回调等待，但不包含进入该帧前的窗口事件轮询。

修复分为三部分：

1. 缓存 ECS 视图、静态碰撞多边形及 AABB。保留固定步长/自适应子步和原始 SAT，不降低物理精度。
2. 精灵、文字、面板合并为一个保持顺序的图集批次。删除逐精灵 UBO 和逐字形像素 Draw Call；一次网格上传后再提交一条绘制命令。
3. 主线程等待渲染回调条件变量，取代 sleep 轮询，消除 Windows 定时调度造成的额外长等待。首次批量绘制之后仍有约 30 ms 帧延迟，正是这一项揭示并修复的。

画质恢复线性过滤，并增加受控 mip 采样、动画帧边缘扩展和算法生成的抗锯齿字形。原有素材分辨率未改动。

验证：根目录 build.bat 全量构建；音频和游戏 CTest；render_scheduling_test（含生产者通知、超时及回调执行线程测试）；实际 OpenGL 三帧截图。
新增碰撞缓存旋转/移动/尺寸/源顶点失效测试，及跨 ECS chunk 边界的视图刷新测试，原玩法测试仍通过。
