# 洞穴与地表洞口

洞穴应用于默认的 `DensityField` 模式；`heightmap` 兼容模式维持原来的地形。实现位于 `Generator/cave_generator.h`，参数集中在 `CaveConfig`。

## 洞道形状

原判定 `min(abs(A), abs(B)) < width` 实际挖出了两组噪声零值面的并集，容易形成扁平裂缝。现在使用 `sqrt(A*A+B*B) < width`，挖掘两组噪声零值交线附近的管状区域。两个方向均需接近零，截面在噪声空间为圆形；世界坐标中的形状会随噪声弯曲和变宽，并非严格等半径圆柱。

默认降低洞道频率到 `0.035`，宽度改为 `0.16` 并连续变化 ±20%，保留少量大洞室。洞室阈值从 `0.66` 提高到 `0.78`，让管状洞道占主导。这是接近旧版 Minecraft 洞道观感的调整，不是其随机游走算法的复刻。

## 裸露洞口

低频、世界坐标确定的洞口区域允许管状洞道穿过地表。普通区域仍保留 6 格屋顶保护，并在额外 8 格深度内逐渐收窄，而不是将洞穴横向切平。大洞室不会直接掀开地表；底部 4 格范围也平滑收窄，`y <= 3` 不挖空。

海床保持封闭：洞口从名义地表高于海平面 4 格的位置开始渐入。洞口下方仍保持岩石/泥土材质，不会因为上方被挖空而变成草地或积雪。

块生成的深层快速路径、地表密度带、邻块参考查询共享同一规则。格点缓存保持精确采样，避免每个体素重新计算噪声哈希。`surfaceEntrances=false` 可用于生成器级别的封顶测试。

## 验证与寻找洞口

`terrain_cave_test` 验证种子确定性、负坐标、缓存范围外回退、地表带边界一致性、洞底保护、洞口连通性及生成耗时。种子 `12345` 的一处测试洞口坐标约为 `(-643, 101, -935)`；对应连通系统向下延伸约 99 格。洞口不是均匀分布，低海拔海岸附近可能没有。

地形算法改变后，同一种子重新生成的洞穴形状也会改变。重启 demo 后，新生成区块使用这些规则。
