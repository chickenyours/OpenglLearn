# 普通外观的十种 Lua 变形尖刺

规范源码为 `Asset/IWanna/Examples/morph_spikes.lua`，安装工具为 `tools/install_iwanna_morph_spikes.py`。十种机关的动作、组合顺序、计时、音效与清理全部用 Lua 实现。宿主补充通用 `on_entity_spawn(ctx,event)` 初始化事件，使编辑器新增实例与 Lua 动态生成实例都能自动获得行为，无需维护房间内的实例名单。

## MyIwana 演示

`run_morph_spikes_demo.bat` 进入独立房间 `morph_spikes_demo`。十段测试区由门依次连通，每段有自己的出生点和存档点；最后一扇门返回第一段。原有四个房间的地形不变。也可以使用 `run_morph_01_vertical.bat` 到 `run_morph_10_staircase_combo.bat` 单独试验某一种机关，或者在编辑器选择 `variant_01`～`variant_10` 出生点试玩。

`tools/add_iwanna_morph_demo.py --project <目录>` 创建这间展示房；检测到同名房间或脚本时会拒绝覆盖，保留开发者修改。演示中没有标注哪一种变形或提前显示攻击范围，调试范围请在编辑器中查看。

## 十种行为

所有模板的普通状态都使用现有 `demo_spike.png`，尺寸 2.5×2.5，完全不透明，具有正常尖刺的蒙版伤害。没有提前闪烁、警告图案、预警音或等待时间。玩家进入检测框后立即开始第一步变换，并播放一次 `Block Change`；后续每一个变换步骤开始时也各播放一次，包括恢复普通形态。动画更新帧与停留阶段不反复播放声音。

表中倍率相对于实例初始尺寸，角度相对于实例初始旋转。动作持续时间会按 1/120 秒物理步长取整，不含默认 1.4 秒冷却。

| 预制体后缀（完整 ID 为 `morph_spike_` + 后缀） | 行为顺序 | 约时长 |
|---|---|---:|
| `vertical` | 纵向长到 5 倍，停留，收回 | 0.54 秒 |
| `horizontal` | 横向宽到 6 倍，停留，收回 | 0.56 秒 |
| `giant` | 宽高同时变为 3.6 倍，停留，恢复 | 0.60 秒 |
| `squash_pop` | 压扁为 2.8×0.35，紧接着弹成 0.8×6，恢复 | 0.65 秒 |
| `cross` | 横展为 6×0.65，再竖展为 0.7×6，恢复 | 0.76 秒 |
| `stutter` | 短伸 3 倍，假收回，随后再伸 6 倍，恢复 | 0.78 秒 |
| `turn_spear` | 先向左转 90°，再拉长为 7 倍横刺，恢复 | 0.67 秒 |
| `windmill` | 变细并拉长 4 倍，绕根部先转 180°、再转 180°，恢复 | 1.20 秒 |
| `diagonal_giant` | 同时斜转 -45° 并放大为 2.5×4，恢复 | 0.66 秒 |
| `staircase_combo` | 横展 3×0.55 → 竖展 0.8×4 → 向右甩 1×5 → 向左甩 2×3 → 恢复 | 1.49 秒 |

默认最大长度为 17.5 世界单位。所有变形阶段、停留阶段和收回过程都使用随贴图尺寸、旋转同步变化的精确蒙版；收回以后仍然是有伤害的普通尖刺。

## 编辑器和实例参数

直接放置上述任一个预制体即可。模板 `role=trigger` 负责独立的感应区域；游戏初始化时 Lua 隐藏控制器，并在原位置创建 `morph_spike_effect` 危险子实体。编辑器仍显示正常尖刺图案和可编辑的检测框。不要把检测框当作放大的伤害框：它只负责开始动作，真正伤害始终来自尖刺贴图蒙版。

| 属性 | 默认 | 作用和范围 |
|---|---:|---|
| 实例 `size` | `[2.5,2.5]` | 普通尖刺尺寸，每轴 0.1～20 |
| 实例 `rotation` | `0` | 初始方向；所有动作角度相对它计算 |
| `variant` | 模板指定 | 上表十个后缀之一 |
| `scaleX` / `scaleY` | `1` / `1` | 在各非普通动作目标倍率上额外乘此值，各 0.25～4；不改变普通待机或假收回的尺寸 |
| `speedScale` | `1` | 动作速度倍率，0.25～3；也改变动作间停留时间，不改变冷却 |
| `cooldown` | `1.4` | 恢复后的冷却秒数，0.05～30 |
| `pivotX` / `pivotY` | `0` / `0.5` | 以初始尺寸为单位、相对于贴图中心的局部支点偏移，各 -1～1；默认底边中心 |
| `sound` | `Block Change` | 每个动作步骤开始时播放；空字符串为静音 |
| `detectionX/Y` | `-3` / `-1` | 既有检测框的偏移，默认靠尖刺左侧 |
| `detectionW/H` | `5` / `6` | 默认左方近身区域的宽高，编辑器可直接调整 |
| `effectPrefab` | `morph_spike_effect` | 真实危险实体模板；应保留默认蒙版尖刺 |

例如实例 `size:[2,3]`、`rotation:90` 的待机形态为横向尖刺。默认底边支点跟随初始旋转，纵向拉伸沿它所指的方向伸长；不需要重新写一套横向代码。`pivotY:0` 则改为围绕中心放大/旋转。

模块会在隐藏控制器、创建危险子实体之前检查参数。组合尺寸不能超过 160，中心运动速度按保守上界限制在 650 单位/秒以内，生成中心必须落在宿主支持的坐标范围；过大的 `size`、`scaleX/Y`、`speedScale` 组合会报告明确错误，应降低倍率或速度。

恢复并冷却后，离开检测框再进入可以重触发；一直站在框内不会自动循环。所有实例共享最多 8 个运行/冷却任务，超出时保持普通危险尖刺形态，不会临时变成无伤害物体。每房最多 64 个该类控制器。

## 实现与生命周期

房间进入回调命令提交后，宿主向有 `event` 属性的实体发出 `on_entity_spawn`。事件的 `name` 为 `morph_spike`，`id` 为稳定实例 ID，`phase` 为 `spawn`；`properties` 为模板/实例合并值，并提供当前 `positionX/Y`、`sizeX/Y`、`rotation`。动态 `spawn` 后紧接的设置尺寸、旋转等命令先应用，再发出初始化事件。

Lua 创建一个没有 `event` 的 `morph_spike_effect`，因此不会递归生成自己。危险子实体的 ID 为 `morph:<序号>:effect`，分配时跳过已存在的 ID；开发者不要手工占用此内部命名空间。动画阶段边界使用同 ID 销毁/重新生成，恢复准确支点；阶段之间用 `set_size`、`set_rotation` 和 `set_velocity` 更新，不需要专用 C++ 变形接口或 `set_position`。

物理步之间可能产生一小步支点误差，默认数值下适合根部微量埋入地格。动画结束和阶段边界均重新校准，不会多轮累积偏移。动态修改控制器位置后，下次启动会以新位置重建支点；待机移动由看守计时器同步。初始化后的 `size/rotation` 和动作参数保存在 Lua 状态中，若要完全替换这些参数，请销毁后重新生成控制器。

每个活动任务只有一个待执行定时器；另一个共享的 0.25 秒看守定时器清理被其他脚本销毁的控制器对应子实体，并重建意外丢失的待机子实体。单次最多回收 8 个、修复 8 个，其余在后续轮次处理；为同一帧的动画阶段切换保留命令预算。销毁控制器后用同一稳定 ID 重新生成，也会重新初始化尺寸、旋转与动作种类，旧子实体和旧任务失效。死亡时清理全部子实体、任务和状态，已排队的旧事件无操作；重生/换房重建 VM。

## 安装与更新

```powershell
python tools/install_iwanna_morph_spikes.py --workshop
python tools/install_iwanna_morph_spikes.py --project D:\Games\MyIwana --room room_01 --room room_02 --room room_03 --room room_04
```

工具不修改房间 JSON 或地形，只创建缺少的预制体、复制现有尖刺图和音效、包装指定房间的外部 Lua 脚本。已有的触发、计时、死亡、初始化回调都被保留。第一次改写前保存 `.before_morph_spikes.bak`；重复安装只更新自己的模块标记区，不重复嵌套包装，也不覆盖开发者已经改过的预制体文件。

实际运行代码位于房间 Lua 的 `BEGIN LUA MORPH SPIKES MODULE` / `END LUA MORPH SPIKES MODULE` 内。项目中的 `scripts/morph_spikes.lua` 是参考副本，当前宿主不通过 `require` 自动加载它。修改规范源码后重新安装，或者直接修改房间嵌入块。

动作表 `patterns` 的每行依次为：宽倍率、高倍率、相对旋转角、变换秒数、停留秒数、是否普通形态。增加新的组合只需扩展该表和对应 JSON 模板；计时、蒙版、声音、冷却与清理框架可以复用。

## 验证
