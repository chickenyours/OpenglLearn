# PixelSandbox 性能记录

测量日期：2026-10-03。CPU：Intel Core i7-14650HX；Windows；clang-cl 20.1.8、Ninja。使用本模块独立 Release 构建，最终结果开启受支持的 IPO。构建与运行命令见 [README.md](README.md#独立-release-基准)。

固定随机种子 `827391`，每个场景预热 30 步，随后计时 120 步。下面是单次运行的 CPU 模拟步耗时，不包含渲染、颜色转换、纹理上传或窗口等待，也不代表最终画面帧率。笔记本功耗、温度及后台任务会影响复测结果。

原始最终结果保存在 [Benchmarks/release-final.jsonl](Benchmarks/release-final.jsonl)，包含阶段耗时、平均访问量、活跃比例及校验值。

## 优化效果与正确性

静止 640×400 场景的平均像素访问量从 256,000 降到 0，P50 从 1.9605 ms 降到 0.0174 ms，约为完整扫描的 1/113。两种执行方式的最终物理校验值均为 `7228158692924236039`。这体现的是静止区块休眠收益，不能外推为动态反应场景同样加速。

首轮 Release 基线未开启 IPO、尚未缓存材料表指针，也没有区块内部重复唤醒的快速路径；原始结果见 [Benchmarks/release-baseline.jsonl](Benchmarks/release-baseline.jsonl)。640×400 混合反应 P50 从 17.1708 ms 降到 14.2591 ms，P95 从 23.5615 ms 降到 19.5698 ms，本次采样均降低约 17%。密集惰性场景没有观察到同等收益，P50 从 7.9008 ms 变为 8.1492 ms，未据此宣称全面加速。

最终 10 组结果与优化前的对应校验值全部相同。功能测试还直接比较休眠与完整扫描在热边界、概率气体、腐蚀／植物及压力驱动场景中的逐步状态。固定随机数按坐标、步数、种子和规则盐值取样，减少工作量不会改变其他像素的随机序列。

此处是同一规则实现前后核对，既不证明与参考游戏逐像素一致，也不保证不同编译器、浮点设置及未来并行策略产生相同位模式。

## 下一步优化依据

640×400 混合反应的平均阶段耗时：空气场 0.1421 ms、传热 5.1051 ms、材料规则与移动 9.9320 ms；100% 区块持续活跃。这类负载的主要成本在材料邻域和热交换，继续改进休眠不能消除它。

当前使用单线程、有确定执行次序的像素更新；没有把线程数当作性能承诺。后续优先建立跨区块写入协议和规则读写范围，再并行空气／热场及区块更新。复杂场景的 P95 已高于 60 Hz 的 16.67 ms 模拟预算，若还计入绘制开销，不能保证 640×400 在所有玩法下稳定 60 FPS。

## 本轮验证

- Debug／Release 核心测试：19 组场景，包括守恒、密度交换、更新戳、相变、燃烧、电流、爆炸、休眠等价和存档回放。
- Render 纹理更新测试：上传字节所有权、区域参数、无效句柄以及 OpenGL unpack 状态恢复。
- 已有 SpriteBatch、RenderTarget、材质管线生命周期、渲染调度和帧命令缓冲回归。
- 实际 OpenGL 隐藏窗口：落沙、火山和电路预设分别运行 64 帧／128 步，读取实际帧缓冲检查画面；无 GL 错误。

这些检查覆盖自动运行路径；尚未进行长时间手动交互和多小时内存稳定性测试。

## 14 种新增材料／装置后的记录

扩展版保留 16 字节 Cell，旧材料走单独的快速分支，新增装置不增加每像素 ECS 查询。基准新增 `elements` 四区实验场景，仍预热 30 步、计时 120 步。原始 10 组场景的最终物理校验值全部保持不变，新增两组结果与全部阶段耗时见 [Benchmarks/release-elements.jsonl](Benchmarks/release-elements.jsonl)。

| 画布 | 场景 | P50 ms | P95 ms | 最终粒子数 |
| --- | --- | ---: | ---: | ---: |
| 320×200 | 新元素实验 | 0.2645 | 0.4268 | 19,056 |
| 640×400 | 新元素实验 | 1.1343 | 2.4613 | 74,633 |
| 640×400 | 密集沙／水／油 | 8.9920 | 10.7050 | 172,721 |
| 640×400 | 九材料混合反应 | 43.9613 | 58.2515 | 226,805 |

新元素实验是分区工作台，活跃区块约为 320×200 的 17.8%、640×400 的 9.6%，不能与整幅持续反应负载直接比较。扩展轮重复采样中，640×400 九材料反应 P50 出现约 21.9～44.0 ms 的明显波动，未修改的热交换阶段也同向变慢。现有测量不能区分系统负载／功耗波动和规则扩展各自的影响，因此不宣称扩展带来性能提升，也不把首版 14.26 ms 作为当前版本的性能保证。后续对比需要固定运行条件再测量。

扩展验证增至 25 组核心场景，增加温控装置不产生点火脉冲、导火索延时、气体反应、泥浆育苗、复制器节拍／唤醒、v1 旧档兼容及 v2 回放。独立 UI 测试覆盖全部分类分页、高 DPI 和宽窗口留边的材料点击映射；新元素预设通过实际 OpenGL 隐藏窗口自检。
