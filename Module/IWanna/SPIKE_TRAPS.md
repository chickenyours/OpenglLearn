# Lua 伸缩尖刺与随机飞刺

`Asset/IWanna/Examples/spike_traps.lua` 用现有 Lua 实体和定时器接口实现三种机关，不增加 C++ 玩法逻辑、素材或平台依赖。规范脚本由安装工具嵌入指定房间，已有苹果环、延迟陷阱、反应方块与开发者回调完整保留。

## MyIwana 演示入口

四个房间的脚本均已接入该模块。`run_spike_demo.bat` 从三段尖刺课程起点开始，`run_spike_demo_left.bat` 与 `run_spike_demo_corridor.bat` 分别直接进入长左刺和随机飞刺通道，便于单独试调。

正常游戏中，第二房间起点左侧 `(-7.5, 17.5)` 的门进入 `spike_course`；完成上层三段课程后回到第二房间原来的 `start`。项目仍为四个房间，第一、第三、第四房间的几何保持原样，第二房间向上扩展，原关卡的世界坐标不变。

课程上刺的基座为 `(25, -59.5)`，埋入地面 0.5 单位；左刺基座为 `(103.8, -68)`，埋入右墙 1.3 单位。埋深补偿 `demo_spike.png` 的透明边距，检测区域仍分别位于基座上方和左方。第三段采用交错平台和有限轨道飞刺，课程实例设为 `seed: 0`，正常游玩使用随机序列。

三种机关的完整运行逻辑均为 Lua，本次没有增加 C++ 运行时业务逻辑；C++ 仅新增回归测试。实际项目六项输入用例和独立预览中的九种随机飞刺组合通关验证均已通过。

## 放置方式

| 预制体 | 用途 | 默认检测框 |
|---|---|---|
| `floor_spike_trap` | 地面细长上刺，伸出后缩回 | 基座正上方 3×9 区域 |
| `left_spike_trap` | 右墙向左伸出的长刺 | 基座左侧 24×8 区域 |
| `flying_spike_trap` | 通道触发有限轨道内的随机横向飞刺 | 基座左下的通道区域 |

控制器使用压力板图案，只负责检测；真正的危险实体使用 `spike_trap_effect`，在工作期间出现并开启尖刺贴图蒙版碰撞。`spike_trap_warning` 为同图的半透明无碰撞预警。不要把控制器当作普通静态危险尖刺使用。

`effectAnchor` 是基座/发射源的实例 ID；默认 `$self` 表示控制器自身中心。可以另放一个锚点并填其 ID，检测框和实际危险位置便可独立调整。检测框仍通过现有 `detectionX/Y/W/H` 编辑并可视化，所有距离使用世界单位。

## 伸缩尖刺

事件为 `telescopic_spike`。`effectAnchor` 指向根部，`orientation` 指定从根部朝外的方向：`up`、`down`、`left` 或 `right`。贴图局部宽度是尖刺粗细，局部高度是尖刺长度；改变方向时 Lua 自动旋转。

| 属性 | 上刺默认 | 左刺默认 | 含义 |
|---|---:|---:|---|
| `length` | 9 | 24 | 最长伸出长度 |
| `restLength` | 0.25 | 0.25 | 开始和收回时的短长度 |
| `thickness` | 1 | 2.5 | 粗细 |
| `delay` | 0.25 | 0.35 | 无伤害预警时间 |
| `extendSeconds` | 0.18 | 0.22 | 伸出时长 |
| `holdSeconds` | 0.15 | 0.3 | 完全伸出后的停留时间 |
| `retractSeconds` | 0.35 | 0.5 | 缩回时长 |
| `cooldown` | 1 | 1 | 收回后冷却时间 |
| `sound` | `apple` | `apple` | 开始伸出时播放，空字符串静音 |

预警无碰撞；伸出、停留和缩回期间有碰撞；收回后销毁效果。冷却结束后可以再次进入检测框触发；一直站在框内不会自动连发。同一控制器工作时忽略重复进入，不同控制器可以并行。

伸缩采用约 1/120 秒的 Lua 小步更新，以实际中心位置校准长度和下一步速度。没有使用不存在的 `set_position` 接口；完全伸出时通过同 ID 的销毁/重新生成恢复准确基座，收回后清理，避免逐次漂移。两个更新点之间最多有约半个步长的根部偏差，基座应略埋入墙或地板，用实体地形遮住误差。实际时间以固定物理帧取整。

## 飞刺与预警

事件为 `flying_spikes`，方向仅允许 `left` 或 `right`。`effectAnchor` 是第 0 条轨道的发射中心，后续轨道按世界 Y 增加 `laneSpacing`。模块从有限轨道中无放回随机选择 `count` 条，先画出这些轨道的半透明预警，再沿同一轨道发射，不会重新抽取危险位置。

| 属性 | 默认值 | 含义 |
|---|---:|---|
| `laneCount` | 5 | 总轨道数，2～12 |
| `laneSpacing` | 4 | 相邻轨道中心间距，至少比尖刺粗细多 1 |
| `count` | 2 | 每次发射数，1～4，必须小于总轨道数 |
| `length` / `thickness` | 2.8 / 1 | 飞刺长度与粗细 |
| `warningSeconds` | 0.6 | 预警时间，至少 0.25 秒 |
| `speed` | 28 | 横向速度 |
| `flightDistance` | 18 | 尖刺**中心**的最大行程 |
| `lifetime` | 1.2 | 最大飞行时间 |
| `minSpawnDistance` | 6 | 发射点到玩家的最小前向间隔 |
| `cooldown` | 1 | 一轮清理后的冷却时间 |
| `seed` | 0 | 0 使用默认随机；正整数使用独立可复现序列 |

一轮至少留出一条空轨道。预警结束时重新检查玩家位置，只有玩家位于发射方向前方、距离至少为 `max(minSpawnDistance, speed×0.2)` 时才生成该轨道飞刺，避免玩家在预警期间走近枪口后被贴脸生成的尖刺击中。不满足条件的轨道跳过，不换到未预警的位置。

清理时间为 `min(lifetime, flightDistance/speed)`。`flightDistance` 测量中心行程，最前端还伸出半个 `length`，此外应预留一物理帧的移动量；设计隔墙时把发射源埋入墙内，并让行程终点早于隔墙。飞刺按速度移动，不靠墙面碰撞停止；不能用超过通道长度的行程让它穿过隔墙影响其他区域。预警覆盖这段飞行范围。

`seed` 每个控制器独立维护，不改动全局随机数状态。相同种子和触发次序会产生相同轨道序列，便于测试；连续触发仍会变化，重进房间才重置序列。

## 生命周期与安装

所有机关合计最多 8 个在执行/冷却的任务，每个任务只有一个待执行定时器；超过限额的进入事件跳过，退出再进入可重试。飞刺总量受任务数和单轮数量共同限制。死亡清理全部预警、伸缩刺和飞刺，旧定时事件变成空操作。重生或换房重建 VM 与实体，不残留危险对象。

```powershell
python tools/install_iwanna_spike_traps.py --workshop
python tools/install_iwanna_spike_traps.py --project D:\Games\MyIwana --room room_02
```

可重复 `--room` 安装多个房间。工具不修改房间 JSON 或地形，仅补充缺少的模板、素材并包装外部脚本。重复执行只更新自己的模块区段，保留完整旧脚本与后来新增的外层包装。

`scripts/spike_traps.lua` 是参考副本；实际运行代码在 `scripts/room_XX.lua` 的 `BEGIN LUA SPIKE TRAPS MODULE` / `END LUA SPIKE TRAPS MODULE` 之间。修改规范文件后重新安装，或直接修改该嵌入块；单独修改参考副本不会影响游戏。

动态实体 ID 为 `spike:<任务号>:effect`、`:warning`，飞刺为 `spike:<任务号>:shot:<轨道号>` 与 `:warning:<轨道号>`；轨道号从 0 开始。模块事件 `lua_spike_trap_task` 专供内部调度。
