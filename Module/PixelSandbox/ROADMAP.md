# PixelSandbox 实施阶段

目标：复现落沙沙箱的主要可组合玩法，在本项目 ECS 和 Render 中建立可测量、可扩展的实现。以可运行交付和测试结果推进；不直接把参考项目的整体引擎搬入本项目。

## 已完成：源码与架构审计

- 确认提供的三个路径对应两套不同实现，记录来源与机制。
- 从 ForestFire 的“每元胞实体”切换为“世界／区块实体＋连续像素组件”，避免粒子内循环承担实体查询和结构变化成本。
- 确定顺序更新、局部更新戳、明确的场／热／材料阶段及引用游戏机制的边界。

## 已完成：阶段 1，材料运动内核

- 16 字节 Cell、O(1) 网格访问、预计算密度交换矩阵。
- 重力、粉末堆积、液体扩散、气体上浮、闭合边界。
- 固定步长、最大追帧预算、固定种子随机、单步与暂停。
- 16×16 区块休眠和带边界唤醒，概率动作不能错误休眠。
- 守恒、移动不重复、边界及完整扫描对照测试。

## 已完成：阶段 2，组合反应

- 水／冰／蒸汽、熔岩／石、沙／玻璃的温度变化。
- 多种燃料、烟、酸的有限容量、盐水、种子与植物。
- 有传播时延和冷却期的电流，火药与燃气的有限半径爆炸。
- 4×4 空气场的压力／速度、温度／气压工具、风驱物质移动。
- 热边界、概率反应、导电与爆炸行为测试。

## 已完成：阶段 3，实验工具与持久化

- `Test/main.cpp` 内运行入口；材料调色板、温度视图、连续笔划、覆盖与擦除。
- 落沙、火山、电路、生态四个预设。
- 版本化存档、事务加载、保存后确定性继续运行。
- Render 通用纹理子区域上传、持久画布纹理、固定四边形、上传／帧背压。
- 隐藏窗口 GPU 自检、PNG／PPM 实际画面捕获。

## 已完成：阶段 4，性能基线与首轮优化

- Debug 和独立 Release 构建，四类负载、两种尺寸、阶段耗时。
- 静止场景验证休眠降低访问量并保持相同物理校验值。
- 真实高反应混合负载覆盖燃烧、腐蚀、相变及爆炸。
- 热循环直接材料表索引、区块内部重复唤醒的快速路径、可选编译器 IPO。
- 优化前后物理校验值逐场景核对；具体实测记录见 `PERFORMANCE.md`。

## 下一阶段 5：规则系统和并行执行

在阶段 5 前已完成一轮材料扩展：新增 14 种材料／装置（土壤、泥浆、雪、两种蜡、氧／氢／CO2、干冰、导火索、电池、加热器、冷却器、复制器），总计 36 种可绘制对象。已接入分类分页、新元素实验预设、存档 v2／旧档兼容，以及反应、供电、生产节拍、休眠等价和 UI 点击测试。

建议顺序：

1. 将反应规则拆分成显式读／写范围及事件队列；低频反应可用定时唤醒替代持续轮询。
2. 用材料配对稀疏表替代高频邻域的重复类型判断，并增加规则注册／数据校验。
3. 为跨区块移动引入所有权和延迟提交；先做空气场并行，再评估棋盘区块＋halo 的物质更新。
4. 在同步参考模式中验证并行前后物理守恒、边界连续性及确定性；公开速度与额外内存代价。

验收：640×400 高反应负载的 P95 在本机基线基础上下降，且不以丢失反应、随机冻结或更改更新频率换取性能。线程数从 1 到多核的结果由同一回放验证。

## 后续阶段 6：复杂物理与编辑体验

- 空气场气密边界、涡度／压力求解、材料热容量与潜热；分离能量粒子层，为光线、激光等机制提供空间。
- 更多电路元件、传感器、阀门及可组合机械行为；基础电池、温控装置和复制器已完成。
- 撤销／重做、区域复制、材料配方编辑、实验项目与回放文件。
- 根据上传占比启用脏矩形合并／纹理局部上传，评估 PBO 环形缓冲；已有 RHI 接口可复用。
- 更大画布和多线程压力测试、长时间交互、内存增长及异常退出恢复。

验收：每个新机制有最小可复现实验和稳定性测试；新模型能力与近似限制一起记录，不宣称与参考游戏逐像素一致。
