# 规则瓦片地图与像素素材

`tilemap.json` 是当前地形的编辑入口。`level.txt` 保留原始对象记录，但其中 `solid` 不再实例化；地形由瓦片地图生成原有 ECS 实体，并附加 `TileCell`（行、列、材质编号）组件。

- 格子边长 2.5 世界单位；原点 `(-100,-45)`，80 列 × 36 行，包含画面外的原机关。
- `layers[].cells` 每行是一个等宽字符串。`0` 表示空格，`1` 表示石砖；`palette` 可扩展编号 `1`–`9`。当前为单一地形层，多层不能在同一坐标重复占格。
- 格子中心为 `origin + (column + 0.5, row + 0.5) × tileSize`，尺寸始终是 `tileSize × tileSize`，没有自由缩放或地块重叠。
- 根据上下左右是否为空，生成 `N=1/E=2/S=4/W=8` 的边缘掩码，匹配 `imagePattern` 中的 `{edges:02}`。例如 `terrain_09.png` 表示上、左外露。顶边带草，内部砖纹连续，侧边与底边有收边。
- `markers` 把命名机关挂在格子上，保留 `cao1/2/3` 与苹果的触发关联。移动或删除对应格时同步修改标记。
- `objects` 通过 `sourceIndex` 引用 `level.txt` 中从 0 开始的对象行（不含表头），覆盖图片、尺寸、位置等。告示牌和存档点放在邻近的地面上，地刺尽量匹配原支撑面的新网格位置。
- `spawn` 是初始复活位置。修改地形时注意保留人物站立空间。

当前迁移结果是 946 个地形格 + 83 个其他对象，共 1029 个初始实体。编辑地图之后运行 `build.bat` 复制资源，或开发时使用 `bin/iwanna_game.exe --assets Asset/IWanna --config Asset/IWanna/gameplay.json` 直接加载源资源。

地形、消失平台、告示牌及存档点使用原创程序化像素素材。16 种地形边缘图为 128×128；告示牌与存档点为 160×192。基于 32×32 / 40×48 像素网格设计，整数放大保留清晰像素边缘，渲染时单独使用最近邻采样。消失平台按格重复绘制，不横向拉伸砖纹。存档点未激活为蓝色，激活后为绿色晶石。未使用网络素材或新增运行时依赖，来源与校验记录见 `tile_art_manifest.json`。

`tools/build_iwanna_tiles.py` 是一次性迁移和美术生成脚本，仅开发时依赖 Pillow。**重新运行会根据原关卡重建 tilemap.json，覆盖手工编辑**，日常编辑不需运行它。旧素材和 `reference` 中的原关卡仍保留。

1920×1080 下，每个地形格对应 32 屏幕像素；视区为 150×84.375 世界单位（16:9），沿用原横向坐标，扩展纵向视野，不拉伸游戏实体。调整窗口大小时保持 16:9 比例。渲染继续使用原 ApplicationWindow + Render/RHI 和单图集批次。
